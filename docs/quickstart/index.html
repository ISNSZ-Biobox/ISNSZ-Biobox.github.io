Quickstart

The shortest path from an empty screen to a finished revision session.

Updated 2026-02-10

The ten-minute session

  1. 1

    Find a topic

    Pick a unit from the Units group in the sidebar, or open All entries to see everything at once. Every row is a single entry.

  2. 2

    Read the entry

    The entry page opens with the summary, then the structured body. The On this page list on the right jumps between sections.

  3. 3

    Bookmark it

    Use Bookmark on the entry to keep it under Bookmarks for later. Bookmarks survive a reload and are the fastest way back to a topic you keep getting wrong.

  4. 4

    Test yourself

    Every entry with recall questions has a Flashcards view. Start a session from the entry itself, or from the global Flashcards page.

  5. 5

    Answer on paper

    Topics with a printable sheet show a worksheet band on the entry. Open it, work on paper, then check the answer key.

What good looks like

A finished session is not "I read the page". It is: you recalled the key point without looking, you got the worksheet question right on paper, and you know which entry you are opening next.

Short and often

Three ten-minute sessions across a week beat one thirty-minute session. The review tools are built for the short session — the flashcard set for a topic is deliberately small.

Common first-session mistakes

  • Reading the whole All entries list as a task list. It is an index, not a syllabus: work one unit at a time.
  • Skipping the worksheet because the entry felt easy. Worksheet questions ask you to apply the idea, which is a different skill from recognising it.
  • Ignoring Also known as at the foot of an entry. Those are the alternate names exam questions use.
